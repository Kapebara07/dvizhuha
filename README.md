# Сайт лаунчера «Движуха»

Статический сайт без сборки: `index.html`, `style.css`, `app.js`, шрифты (урезаны до кириллицы и латиницы, woff2) и картинки.
Можно выложить на любой хостинг статики, просто скопировав папку.

## Что где менять
- **Ссылка на установщик** — `index.html`, тег `<a id="download" href="…">`. Сейчас там
  `https://github.com/dvizhuha-mc/dvizhuha-mc.github.io/releases/latest/download/Dvizhuha-Launcher-Setup.exe`:
  такая ссылка всегда ведёт на файл из последнего релиза, если загружать его под этим именем.
- **Подпись под кнопкой** (размер, версия) — там же, `<span class="stub-sub">`.
- **Запасная ссылка** — `index.html`, `<p id="mirror" data-href="">`. Впиши адрес (например, Google Диск) — строка
  «Не качается? Запасная ссылка» появится сама.
- **Адрес сервера** — `app.js` (`HOST`) и в `index.html` (табло и подвал).
- **Скриншот** — `img/launcher.webp` и `img/launcher.png` (662×504, обрезка окна лаунчера без табло).

## Онлайн на табло
Браузер не может сам опросить Minecraft-сервер, поэтому `app.js` берёт онлайн у api.mcstatus.io, а если тот не ответил —
у api.mcsrvstat.us. Оба стоят за Cloudflare, который в РФ часто режут. Тогда табло пишет «онлайн не загрузился»;
на скачивание это не влияет.

## Как выложить на GitHub Pages
Сайт живёт в организации `dvizhuha-mc`, репозиторий `dvizhuha-mc.github.io`, поэтому адрес — `https://dvizhuha-mc.github.io/`.
1. Залить изменения в ветку `main` — Pages пересоберётся сам за минуту.
2. Settings → Pages → Deploy from a branch → `main`, папка `/ (root)` (уже включено).
3. Releases → Draft a new release → тег `v1.0.0` → прикрепить `Dvizhuha-Launcher-Setup-1.0.0.exe`,
   **переименовав в `Dvizhuha-Launcher-Setup.exe`** (в релиз можно до 2 ГБ на файл; в сам репозиторий 200 МБ не влезут).
4. При новой версии лаунчера — новый релиз с файлом под тем же именем; сайт менять не нужно, кроме подписи с версией.

## Донаты (DonationAlerts / DonateX)
Окно «Поддержать сервер» открывает страницу сервиса и копирует в буфер «Ник: … · Discord: …» (его потом разбирает мод DvizhDonate).
`data-da` и `data-donatex` у `#donateDialog` — адреса страниц доната (`https://www.donationalerts.com/r/<имя>`, `https://donatex.gg/...`);
пустой — этой кнопки нет, пустые оба — «оплата пока не подключена». Старая форма ЮMoney спрятана (`data-provider="yoomoney"` вернёт её).

## Админ-страница `/admin/` («Штаб»)
Переводы и действия мода (МСК), донатеры, игроки лаунчера, скачивания с GitHub. Данные лежат в `admin/feed.json` ЗАШИФРОВАННЫМИ
(файл не в git: его кладёт `tools/fetch-admin-feed.mjs` при каждой сборке Pages, не ответил сервер — остаётся опубликованный). Расшифровка в браузере
паролем (PBKDF2 → AES-GCM, `admin/decrypt.js`). Ключ для сервера и пароль делает `DvizhFriends/tools/make-admin-key.mjs`. Страница с `noindex`, ссылок на неё нет.
